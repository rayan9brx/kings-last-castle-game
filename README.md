# King's Last Castle Game

King's Last Castle is an object-oriented game project developed in C# with MonoGame.
The project focuses on game logic, class design, player interaction, collision handling, and structured software development in a team environment.

## Overview

This project was created as part of a university software development project.
The main goal was to design and implement a game using object-oriented programming principles and a clean project structure.

The project demonstrates practical experience with:

* C# development
* Object-oriented programming
* Game logic implementation
* Class-based architecture
* Collision and movement logic
* Team-based development with Git and GitHub

## Technologies Used

* C#

## Key Features
